# bcmsh has moved

The notes that used to live here have grown into a full reference for the
Broadcom diag shell (`bcmsh` / `bcmcmd`, the `drivshell>` prompt) on SONiC:

**➡ <https://bcmsh.sonix.network/>**

It covers every command — including the ones `help` does not list — with
examples, plus how-tos for KNET, packet capture, link debugging, L3 and Cint.
